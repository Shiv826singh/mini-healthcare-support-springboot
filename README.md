# CareHelp - Mini Healthcare Support Web App

## Internship Assignment Version

A small Spring Boot web app focused only on the core mini-app requirements:
- Landing page
- Basic symptom checker
- Emergency help
- Medical disclaimer
- Responsive UI

## Tech Stack
- Java 17
- Spring Boot 3.5.5
- Thymeleaf
- HTML/CSS

## Run in IntelliJ IDEA
1. Extract the ZIP.
2. Open the project folder in IntelliJ IDEA.
3. Set Project SDK to Java 17.
4. Allow Maven to download dependencies.
5. Run `MiniHealthcareApplication`.
6. Open: http://localhost:8080

No MySQL or external database is required.

## Note
This is an educational/demo healthcare support app. The symptom checker gives only general guidance and is not a diagnostic tool.
